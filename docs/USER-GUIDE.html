RelayKey User Guide

RelayKey controls the local oc-relay service from the macOS menu bar. It has no Dock icon or main window. Quitting RelayKey does not stop the relay.

Open RelayKey

Open ~/Applications/RelayKey.app in Finder, or run:

open "$HOME/Applications/RelayKey.app"

Click its menu bar icon to see the relay status and controls. A filled bolt in a circle means the relay is running. RelayKey checks status every five seconds; use Refresh to check immediately.

Menu controls

ControlWhat it does
StartStarts the stopped local relay.
StopStops the running local relay.
RestartRestarts the running local relay.
RefreshChecks the current relay health now.
Model (global)Selects a Chat Completions model for future requests through this relay.
Copy Base URLCopies exactly http://127.0.0.1:8788.
Open LogOpens ~/Library/Logs/oc-relay.log. The control is disabled when the file does not exist.
QuitCloses RelayKey, leaving the relay in its current state.

When to switch

  • For the current LM Studio relay, keep MiMo Flash or Kimi K2.7 Code for routine work; move to MiMo Pro when the first pass stalls or the design matters.
  • Use GLM-5.3 or Kimi K3 for a second opinion rather than as an always-on default. Their five-hour estimates are 220 and 110 requests.
  • Qwen3.8 Max and Grok 4.7 are other scarce options at 160 and 169 estimated requests per five hours. Keep them for a specific comparison, not routine turns.
  • DeepSeek V4.1 Flash currently has a high listed allowance; confirm it in the console before relying on it because Go limits can change.
  • MiniMax M2.7 remains available, but Artificial Analysis now marks it deprecated and points to M3.

LM Studio compatibility: OpenCode Go exposes different protocols by model. The current LM Studio OpenAI-compatible plugin calls /chat/completions, so models listed by Go on that endpoint are candidates for this relay. Models on /messages (including MiniMax M3 and Qwen3.8) need a translator; models on /responses (including Grok and Muse) need separate verification. The current relay does not translate between these protocols. Check the Go endpoint table and LM Studio plugin source. Listing a model here is not a successful live compatibility test.

Privacy: OpenCode lists no model training and zero-day retention for the recommended paid MiMo, MiniMax, and GLM models. DeepSeek's zero-retention agreement is listed only through 30 September 2026. Muse Spark 1.3 Contributor permits Meta to train on prompts and completions and is region-limited, so it is not a default here. Grok 4.7 is listed with 30-day retention. Treat Space Bunny's undisclosed identity and temporary availability as reasons to use it only for low-stakes material. Go privacy table.

Artificial Analysis scores describe model variants tested by Artificial Analysis, not the exact performance of a Go-hosted coding session. Its current pages report 46 for MiMo-V2.6-Pro and 29 for MiniMax M3. Model IDs were checked against OpenCode's live Go model list.

Choose a model

In LM Studio, keep Use Custom Model selected and enter a valid Chat Completions ID in Custom Model, such as mimo-v2.6-flash. LM Studio requires this field before it sends a request. RelayKey overrides that ID when a global model is selected.

Open Model (global) and choose a model. The checkmark appears after the relay confirms the change. The choice affects future requests from every client using this relay, including later turns of an existing LM Studio chat. It does not change LM Studio's visible Custom Model setting or interrupt a response already streaming.

Choose Use client model to return to the model sent by LM Studio. The choice persists across relay restarts. This menu lists only models that OpenCode Go documents for Chat Completions; listing a model does not confirm access on your account. See the Go endpoint table.

Troubleshooting

What you seeWhat to do
No menu bar iconOpen the app using the command above. RelayKey does not appear in the Dock. If the icon still does not appear, check whether the app is running with pgrep -x RelayKey.
StoppedChoose Start, then wait for Running · Port 8788.
Not InstalledRelayKey cannot find an executable ~/.local/bin/oc-relay. Check with test -x "$HOME/.local/bin/oc-relay"; install or repair the relay CLI before using Start.
Relay UnhealthyChoose Refresh. If it remains unhealthy, check the service with the status command below and inspect the local log using Open Log.
Start, Stop, or Restart Failed · Exit NChoose Refresh to check the current state. If the action still fails, check the service status and local log. A timeout may appear as exit 124.
Open Log is disabledThe log file does not exist at ~/Library/Logs/oc-relay.log. Check that the relay CLI is installed and has been run.
Model menu says UnavailableStart the relay and install a version of oc-relay with model-selection support. The menu stays unavailable with older versions or invalid selection state.
Model change failedChoose Refresh and check the selected ID with oc-relay model show --json. The menu does not show a new choice until the relay confirms it.
LM Studio says “Missing custom model”Choose Use Custom Model in LM Studio and enter a valid Chat Completions ID in Custom Model. The field must be filled even when RelayKey has a global model selected.

To check the service without printing recent log lines:

"$HOME/.local/bin/oc-relay" status | grep -E '^(Service|Health):'

Keep API keys, relay configuration, and log contents out of screenshots and support messages.

Update or remove

The installed copy is ~/Applications/RelayKey.app. Updating it requires a new build from the RelayKey repository and replacement of that app bundle. Quit RelayKey before replacing it, then open the new copy. Removing the app does not remove or stop oc-relay.
